Every system message in Alerts and Jobs now renders as a proper chat message — a sender avatar + name + time, and one consistent card. The card shows a title, a severity / status badge, and device / area / person chips, with a coloured left bar (red critical, amber warning, green resolved, blue info). Tap a card to expand the detail inline — the reading vs. threshold, when it was raised, and actions (Open device, Create job, Acknowledge for alerts; View job, Start, Done for jobs). The same card shell is used in every channel, so Site/DM messages, alerts and jobs all look and feel the same. (The top alert and first job are shown expanded.)
